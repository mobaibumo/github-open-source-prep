# 中英文项目说明

中文 `README.md`，英文 `README.en.md`，顶部互相链接。若已有不同语言路径或外部引用，优先保留兼容链接再迁移，不制造失效入口。

## 内容选择

根据项目规模取舍，通常按新读者的使用顺序组织：

1. 项目名称、一句话用途、适用人群。
2. 实际效果预览（项目已有或经授权制作），以及关键能力。
3. 最短可行的快速开始：前提、安装/获取、第一次使用、预期结果。
4. 实用示例、必要配置和常见问题。
5. 有帮助时提供目录导航；复杂内容链接至 docs。
6. 已知限制、贡献入口、许可证与第三方致谢。

素材项目用获取、打开和使用方式替代代码安装教程；Skill 项目写清安装位置、依赖、触发方式和自然语言示例。没有的功能、截图、在线演示、包发布和支持平台不生成虚假入口。规划功能与已实现内容明确区分。

## 双语一致性

两种语言信息等价，术语稳定，文字自然。命令、文件名、环境变量、链接目标与输出示例应一致，必要的平台差异明确标注。代码块中的注释可以翻译，机器标识不能翻译。后续同步根据实际差异同时维护两个文件，保留无关段落及用户措辞。

## 参考成熟项目

匹配项目类型、读者和交付形式，再看维护状态与社区使用情况，星数仅作辅助。阅读真实 README 后提炼“为何采用这种结构”，每个项目取适用部分。禁止照搬品牌图、赞助信息、贡献者统计、无实际工作流的状态徽章、排名宣传或大公司 CLA。

## 校验

- 在项目根目录尝试关键命令，核对依赖与配置示例；有破坏性或付费副作用的示例不直接运行。
- 检查 Markdown 文件的相对链接、大小写、锚点、图片和中英切换。
- 公共说明不含个人机器路径、真实密钥、私有账号内部信息。
- 缺许可证或权利声明时清楚记录待办，不捏造许可结论。
- 输出简明验证结果；未实际执行、缺环境与已失败分别描述。
